# Product Vision

Build a simple groceries list web app that helps a household quickly plan shopping.

## Target users

- People planning grocery trips
- Families sharing a simple list
- Anyone who wants a lightweight checklist

## Core value

The app should make it fast to add, review, and complete grocery items.

## Non-goals for the first version

- Real-time collaboration
- Payments
- Barcode scanning
- Store integrations
