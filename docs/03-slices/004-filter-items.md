# Slice 004: Filter Items

## Goal

Allow the user to filter the list by all, active, and bought items.

## User story

As a shopper, I want to filter the list so that I can focus on what remains.

## Scope

Included:

- Filter controls: All, Active, Bought
- Current filter state
- List updates based on selected filter

Not included:

- Category filters
- Search
- Persistence

## Acceptance criteria

- All shows every item
- Active shows items not bought
- Bought shows items marked bought
- Current filter is visually clear
