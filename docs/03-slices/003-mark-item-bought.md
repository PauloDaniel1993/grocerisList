# Slice 003: Mark Item Bought

## Goal

Allow the user to mark grocery items as bought or not bought.

## User story

As a shopper, I want to mark items as bought so that I can track progress while shopping.

## Scope

Included:

- Checkbox or button to toggle bought state
- Visual style for bought items
- Accessible label for the toggle

Not included:

- Filtering
- Persistence
- Bulk actions

## Acceptance criteria

- User can mark an item as bought
- User can unmark an item
- Bought items are visually distinct
- Toggle is keyboard accessible
