# Slice 002: Add Grocery Item

## Goal

Allow the user to add a grocery item with a name and category.

## User story

As a shopper, I want to add items to my grocery list so that I can plan my trip.

## Scope

Included:

- Add item form
- Name input
- Category select
- Required name validation
- New items appear in the list

Not included:

- Persistence
- Filtering
- Multiple lists

## Acceptance criteria

- User can type an item name
- User can select a category
- Submitting adds the item to the list
- Empty names are rejected with a visible validation message
- Form clears after successful submit
