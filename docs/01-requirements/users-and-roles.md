# Users and Roles

## Roles

### User

A normal authenticated shopper.

Can:

- Log in
- View the grocery list area
- Edit their own profile details

Cannot:

- Access admin pages
- Edit other users

### Admin

A privileged user who can manage access to the app.

Can:

- Log in
- View the grocery list area
- Edit their own profile details
- View users in the admin area
- Edit basic user details

Cannot in Slice 000:

- Delete users
- Suspend users
- View audit logs
